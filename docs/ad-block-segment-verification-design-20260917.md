# 广告切片唯一键与隔离验证回放设计

## 目标

为每条广告切片生成并持久化独立稳定键，在 mobile 与 leanback 广告统计列表中单独展示；用户点击“验证”后，通过隔离的 Media3 预览播放器播放该切片或最小 HLS 上下文，并明确反馈可播放、疑似误杀或因上下文缺失无法验证。

## 边界

- 不修改广告识别规则、移除阈值和正式播放策略。
- 预览播放不复用正式播放器会话，不修改播放历史。
- 持久化日志不保存带鉴权参数的原始 URL。
- 原始预览上下文仅保存在有容量和有效期限制的内存缓存中。
- 旧日志没有预览上下文时明确显示不可验证，不伪造播放地址。

## 实施

1. 以规范化后的资源定位信息生成稳定摘要，加入 AdBlockLog 并随现有 JSON 存储持久化。
2. 在 HlsManifestCleaner/HlsAdblockPipeline 的移除明细链路中保留生成最小预览清单所需上下文。
3. 新增预览上下文缓存和最小 HLS 清单构造器，覆盖初始化段、密钥、字节范围和相对 URI。
4. 新增与正式播放隔离的 Media3 预览入口。
5. mobile 与 leanback 日志行增加独立键和验证操作。
6. 增加唯一键稳定性、敏感参数隔离、预览清单和旧记录降级测试。

## 验证

- 定向 JVM 单元测试。
- mobile 与 leanback 编译通过。
- task_guard check。
- 差异审计后由 task_guard finish 创建提交和恢复标签。
